# Campus Exchange

Beginner-friendly Web Technology semester project based on the supplied wireframe.

## Folders

- `Client Side Web pages`: student marketplace interface.
- `Admin`: administrator dashboard.

- `index.html`: deployment entry page that opens the client website.

## How to run

1. Open `Client Side Web pages/client.html` in a browser.
2. Open `Admin/admin.html` in another browser tab for the admin view.
3. No server or installation is required for this prototype.

## Technologies used

- HTML5 semantic elements and forms
- CSS3 responsive layout with grid and media queries
- Vanilla JavaScript for simple search, navigation, forms, cart, wishlist, and admin actions

This is a front-end prototype. A database, authentication, and real payment system can be added later.
